# Slider song files

Song lyric files (`.txt`) for the slider app.

## Song file format

```
[Meta]
languages: km, en

[Title]
Song title

[Verse 1]
...

[Chorus]
...
```

See [sample.txt](sample.txt) for a blank template.

## Importing songs

Songs can be imported from khmerworship.com and campraisemusic.blogspot.com with the **song-scraper** tool, kept in the `song-scraper` folder next to this one (`Desktop\Test\song-scraper`). It saves songs into its own `output/` folder. Copy the songs you want into this folder, then edit the copies here.
